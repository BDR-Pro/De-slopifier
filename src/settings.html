De-slopifier / Settings

A feed closer to your circle.

Keep posts by the accounts you follow and, optionally, the accounts they follow. Filtering and saved lists stay local. Optional automatic sync reads your network directly from X.

1. Choose your account and behavior

The active X account must match this handle. Switch this setting when switching accounts. Network filtering is paused when the signed-in account cannot be identified; ad hiding can remain active.

Best-effort hiding of marked promoted posts on Home, including ads from accounts you follow. It does not change X account settings, stop all ad downloads, or block every ad format. With filtering enabled, ads can be hidden before your following lists are ready.

When unchecked, both Home tabs are filtered. Profiles, search, replies and notifications are never filtered.

Removing nodes can interfere with X's page rendering. Hiding is the default. Neither mode prevents initial network downloads or guarantees that X will not record impressions.

2. Automatic following sync — no scrolling

Connect X once to download your following list and the lists of people you follow. New follows and unfollows are picked up automatically; no scrolling or CSV imports are required.

Setup required: This uses the official X API, not your website login cookies. Configure an X OAuth 2.0 public-client app and API access first. X API reads may incur charges, especially for large second-degree networks. Set a spending limit in the X Developer Console; the request cap below is not a dollar cap.

Choose a Native App or Single Page App (public client). Register the callback shown above exactly. Do not paste your password, cookies, client secret, or bearer token. See docs/AUTO-SYNC.md in the source package.

By default, network filtering waits for complete initial coverage; ad hiding can still work. If a list is unavailable or a safety/request cap is reached, it is not silently treated as empty. Disable second-degree filtering for direct-follows-only operation.

Automatic sync is not configured.

3. Manual lists — optional fallback

Only lists belonging to your account and its direct follows affect the filter. Lists for other accounts are ignored. A missing list means incomplete coverage, not proof that someone is outside your network.

Capture is a best-effort reading of visible account cards. Review for suggested accounts or other mistakes. Scroll the entire list before calling it complete. Protected or unavailable relationships are not bypassed.

One handle per line; commas, spaces, @handles and X profile URLs are also accepted. Do not paste profile bios or tweet text.

Replace removes stale follows from that list. Merge only adds accounts and marks the result partial. With automatic sync enabled, API snapshots replace manual edits to the active network. Edit one copy of the same list at a time.

4. Import or back up the graph

Import the included JSON format, or export your reviewed lists. JSON never executes as code.

Import overwrites only the list owners present in the file, changes your configured handle, and disables filtering until you review it. Other saved lists stay stored. Export includes relationship handles; keep the file private.

The popup shows cumulative blocked posts for this tab since reload or Reset, split into network filtering and ads. Stable post IDs are counted once; cards without IDs are an estimate. Prototype: selectors must be checked against your live X layout. Automatic sync is opt-in and requires X API setup. OAuth tokens stay in extension-origin credential storage, separate from content scripts and exports. Requests go directly to X; no developer backend, telemetry, cookies, DMs, passwords or social-write actions. Locally stored data is not separately encrypted.
